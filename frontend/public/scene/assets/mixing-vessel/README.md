# mixing-vessel.glb

Schematic mixing vessel: metal base and band, glass body and rim. Contents, paddle and bubbles stay procedural.

- Blender source: `scripts/blender/build_assets.py` (function `build_mixing_vessel`)
- Blender version: 5.3.0
- Export: glTF 2.0 binary (GLB), Y-up, applied modifiers
- Origin: base centre, +Y up in the exported file

Regenerate with:

```sh
"C:/Program Files/Blender Foundation/Blender 5.3/blender.exe" -b --python scripts/blender/build_assets.py
```
