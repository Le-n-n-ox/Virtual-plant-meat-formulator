# processing-line.glb

Schematic conveyor rail, legs and bed. Tread slats, station barrels and beacons stay procedural so status colours remain dynamic.

- Blender source: `scripts/blender/build_assets.py` (function `build_processing_line`)
- Blender version: 5.3.0
- Export: glTF 2.0 binary (GLB), Y-up, applied modifiers
- Origin: base centre, +Y up in the exported file

Regenerate with:

```sh
"C:/Program Files/Blender Foundation/Blender 5.3/blender.exe" -b --python scripts/blender/build_assets.py
```
