# ingredient-bin.glb

Schematic ingredient hopper: base, foot ring, glass wall, rim and measurement ticks. The fill level is drawn procedurally on top.

- Blender source: `scripts/blender/build_assets.py` (function `build_ingredient_bin`)
- Blender version: 5.3.0
- Export: glTF 2.0 binary (GLB), Y-up, applied modifiers
- Origin: base centre, +Y up in the exported file

Regenerate with:

```sh
"C:/Program Files/Blender Foundation/Blender 5.3/blender.exe" -b --python scripts/blender/build_assets.py
```
