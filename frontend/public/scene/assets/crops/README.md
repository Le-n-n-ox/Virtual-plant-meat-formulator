# crops.glb

Four ingredient containers and twelve crop toppers plus Crop_Generic. An ingredient is shown as a container chosen by its form with a topper chosen by its crop; MAT_Natural is shared by every topper so the crops keep their own colours and stay cheap.

- Blender source: `scripts/blender/build_assets.py` (function `build_crops`)
- Blender version: 5.3.0
- Export: glTF 2.0 binary (GLB), Y-up, applied modifiers
- Origin: base centre, +Y up in the exported file

Regenerate with:

```sh
"C:/Program Files/Blender Foundation/Blender 5.3/blender.exe" -b --python scripts/blender/build_assets.py
```
