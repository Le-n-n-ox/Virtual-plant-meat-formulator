# Data acquisition and readiness

This folder is for source files and generated imports. Keep original files unchanged, record their version and retrieval date, and retain row/page references for every imported value. Never convert a missing value to zero. A dataset must not be promoted into the product catalogue until its units, food identity, preparation state, provenance, and reuse rights have been reviewed.

## What Python packages can and cannot provide

There is no Python package identified that supplies validated Kenya-specific food composition together with laboratory texture measurements for plant-meat extrusion. Packages provide transport and file handling, not the underlying evidence. `httpx` and `pandas` are already in the backend for API access and tabular work. Add an Excel reader when the official workbook can be downloaded; keep source-specific parsing in `app/ingestion/`. A downloaded value still needs its source ID, source row, unit, basis, method/flag, and licence status.

## Remaining inputs before production data can be activated

1. If the project later becomes commercial, obtain FAO permission for KFCT reuse before commercial distribution.
2. Review and structure the extracted recipe-book inventory against the PDF. The roster count now matches the published 142, but PDF layout/font extraction can distort text, and the inventory retains whole recipe sections rather than parsing ingredient quantities, steps, or nutrient values into fields. Validate the two 15066 variants, the appendix-only 15083 record, code 15021 (`Hard boiled eggs`) in the workbook, nutrient values, and units before activation. Never fill missing nutrients with zero. The original workbook's copyright notice permits non-commercial research with acknowledgement; contact FAO for resale or other commercial use rights.
3. The CSIRO dataset can support non-commercial exploration only. For a commercial model or prediction claims on Kenyan ingredients, collect project-owned measurements with ingredient identity, formulation, extrusion conditions, test method, units, replicates, and raw results.
4. Verify that KAMIS provides fresh Nairobi Wakulima wholesale observations and permits this reuse. Preserve each quoted unit and date; normalize to KES/kg only when the source unit supports a documented conversion. Do not infer prices from nutrient data.
5. Validate the transcribed FAO reference patterns with a nutrition expert before exposing scores. Keep the default unset until approved. Do not report DIAAS without amino-acid-specific ileal digestibility data.

Raw source files are ignored by Git. For licensed or large files, keep them in access-controlled storage and use DVC remote storage only after rights review.

## Project-owned measurement templates

`templates/formulation_components.csv`, `templates/texture_measurements.csv`, and `templates/market_price_observations.csv` are header-only collection templates. Link each component row and each per-metric specimen measurement through `formulation_id`/`sample_id`; record actual measured or quoted values with source, methods, units, date, and provenance. Do not fill them with model estimates or inferred prices. Price records need one row per market observation. Keep cost features disabled until price-source reuse rights and matching coverage are confirmed.

To prepare the downloaded CSIRO CSVs for local analysis, run `python -m app.ingestion.import_csiro_texture` from `backend/`. The generated JSONL is ignored by Git, and every record carries the dataset citation, source file/row, and CC BY-NC-SA 4.0 restriction. The raw files are available from the [CSIRO collection](https://data.csiro.au/collection/csiro:73387).

To regenerate the KFCT review import, run `python -m app.ingestion.import_kfct_workbook` from `backend/`. By default it reads the downloaded workbook in `raw/` and writes an ignored JSONL candidate file and summary in `processed/`. The importer uses the Python standard library and preserves workbook row references, nutrient units, source text, non-numeric flags, statistics, sample counts, and missing-value columns.

To regenerate the recipe-book text inventory, install/use `pypdf` and run `python -m app.ingestion.import_kfct_recipe_book` from `backend/`. For an ephemeral environment, `uv run --no-project --with pypdf python -m app.ingestion.import_kfct_recipe_book` avoids changing project dependencies. It writes an ignored JSONL inventory, count/reconciliation summary, and extracted text. This remains a review artifact; it does not parse recipe ingredients or promote nutrient estimates into structured values.
